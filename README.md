# 颜色切换小程序

一个简单的微信小程序，点击按钮可以在不同的颜色之间切换。

## 功能特性

- 点击按钮切换显示区域的背景颜色
- 8种预设颜色：珊瑚红、薄荷绿、天空蓝、抹茶绿、柠檬黄、薰衣草紫、向日葵橙、粉色
- 颜色名称实时显示
- 圆角卡片设计
- 平滑的颜色过渡动画

## 项目结构

```
├── app.js              # 小程序主逻辑
├── app.json            # 小程序全局配置
├── app.wxss            # 小程序全局样式
├── sitemap.json        # sitemap 配置
├── project.config.json # 项目配置
└── pages/
    └── index/
        ├── index.js    # 页面逻辑
        ├── index.json  # 页面配置
        ├── index.wxml  # 页面结构
        └── index.wxss  # 页面样式
```

## 使用方法

1. 下载完整项目文件夹
2. 打开微信开发者工具
3. 导入项目文件夹
4. 填写 AppID（可以先使用测试号）
5. 点击编译运行

## 技术实现

- **框架**：原生微信小程序框架
- **样式**：WXSS（微信样式表）
- **逻辑**：JavaScript
- **结构**：WXML（微信标记语言）

## 预览效果

运行后在界面中央会显示一个颜色卡片，点击下方的按钮即可切换到下一种颜色，卡片背景会平滑过渡到新的颜色。
